From download to launch

Your first launch, explained.

You need Windows x64 and a complete, compatible local Minecraft 26.3 installation. An unrelated JAR version will not work.

Download and extract everything

Use Get started, then download the ZIP. Right-click it and choose Extract All. Keep both EXEs, Start-Custom.ps1 and the included files in the same folder.

Start the custom launcher

Right-click Start-Custom.ps1 and choose Run with PowerShell. If Windows blocks it, read the message and contact us; do not disable your antivirus or system-wide security settings.

Select your local game files

Select an installed Horizon version. On Home, choose your existing matching installation path or use Choose jar…. Press Prepare. Alternatively, use Automatic to search supported local locations and prepare.

Set your profile, then play

Choose your player name before multiplayer and start the game. Add the server address in Multiplayer. A server requiring Microsoft authentication needs a valid account session; an offline name cannot replace it.

A few things to know

Before you jump in.

Does this include Minecraft assets?

No. Supply your own complete compatible local installation. Native preparation does not download the full game or repair missing assets. Other Java-instance features are separate.

Automatic cannot find my files. What now?

Choose the JAR manually and check the installation path. The matching 26.3 JAR and required assets must exist locally. Automatic searches supported locations, not every folder on your drive.

Why does a server ask me to sign in?

Some servers require an authenticated Microsoft session. This build does not bypass server authentication, and compatibility with every server is not guaranteed.

What has been tested?

GitHub Actions passed the launcher tests, encrypted-login regression test and both Windows builds. A short isolated launcher startup check passed. Live multiplayer and complete setup on every PC have not been verified for this release.

Why is there an advertising step?

The download flow can take you to LootLabs, an external monetization service supporting this project. You will see a clear notice before leaving. The final file page has no embedded advertising scripts.

Where can I report a problem?

Email rilexthedev@gmail.com with build 3324020 and the error message. Do not send passwords, session tokens or private account information.
